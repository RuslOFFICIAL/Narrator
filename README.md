# Narrator bot for Discord.

Check commands by "/" or in code. To chech formats of command, please check file "[formats.md](docs/formats.md)".

Sounds should be in '[sounds](sounds/)' directory of root directory of this project. Sounds file should be in format '.mp3'.

# Version.
- Change version only in 'package.json' file.
- Do not change version in 'package-lock.json' file.
